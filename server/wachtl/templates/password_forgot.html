Passwort vergessen?

Wachtl verschickt keine Links per E-Mail. So bekommen Sie ein neues Passwort:

Sie haben ein normales Konto

Bitten Sie einen Administrator von Wachtl. Er setzt Ihr Passwort unter Verwaltung › Benutzer › Passwort zurücksetzen neu. Eine Sperre nach Fehlversuchen ist damit ebenfalls aufgehoben.

Sie sind der Administrator

Auf dem Wachtl-Server einen der Befehle ausführen und das neue Passwort zweimal eingeben:

Linux (Docker), im Ordner /opt/wachtl/deploy:

sudo docker compose exec app flask --app wachtl create-user admin --role admin

Windows, PowerShell als Administrator:

& "C:\Program Files\Wachtl Server\wachtl-server.cmd" create-user admin

Ein gesperrtes Konto wird ohne Zutun nach 15 Minuten wieder frei.
