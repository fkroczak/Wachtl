Passwort vergessen?

Sie haben ein normales Konto

Bitten Sie einen Administrator von Wachtl. Er setzt Ihr Passwort unter Einstellungen › Benutzer › Passwort zurücksetzen neu.

Sie sind der Administrator

{% if windows %}

Melden Sie sich am Wachtl-Server (Windows) an und öffnen Sie im Startmenü Wachtl › Admin-Passwort zurücksetzen. Windows fragt nach Administratorrechten, danach geben Sie das neue Passwort zweimal ein.

{% else %}

Melden Sie sich per SSH am Wachtl-Server an und führen Sie aus:

sudo /opt/wachtl/deploy/passwort.sh

Dann das neue Passwort zweimal eingeben. Liegt Wachtl in einem anderen Ordner, steht der Befehl am Ende der Ausgabe von setup.sh.

{% endif %}

Das Konto wird dabei auch entsperrt. Nach 5 Fehlversuchen ist es sonst 15 Minuten gesperrt.
