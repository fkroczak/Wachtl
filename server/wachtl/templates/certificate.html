Zertifikat installieren

Wachtl stellt sich sein Zertifikat mit einer eigenen Zertifizierungsstelle aus, der Wachtl-CA. Ist sie auf dem Gerät als vertrauenswürdig hinterlegt, öffnet der Browser Wachtl ohne Sicherheitswarnung – auch nach jeder automatischen Erneuerung des Server-Zertifikats. Die Wachtl-CA gilt nur für die Adressen dieses Servers.

Zertifikat herunterladen

Gültig bis {{ cert.not_valid_after_utc.strftime('%d.%m.%Y') }}. Fingerabdruck (SHA-256) zum Vergleichen:

{{ fingerprint }}

Windows

PCs mit Wachtl-Probe und der Windows-Server: nichts zu tun. Das Setup legt das Zertifikat automatisch unter Vertrauenswürdige Stammzertifizierungsstellen ab und entfernt es bei der Deinstallation wieder.

Andere PCs: Datei öffnen › Zertifikat installieren › Lokaler Computer › Alle Zertifikate in folgendem Speicher speichern › Vertrauenswürdige Stammzertifizierungsstellen. Für viele PCs per Gruppenrichtlinie: Computerkonfiguration › Richtlinien › Windows-Einstellungen › Sicherheitseinstellungen › Richtlinien für öffentliche Schlüssel › Vertrauenswürdige Stammzertifizierungsstellen.

macOS

Datei öffnen, Schlüsselbund System wählen. Danach in der Schlüsselbundverwaltung doppelt auf „{{ (cert.subject.get_attributes_for_oid(cn_oid)[0].value) if cert else 'Wachtl CA' }}“ klicken › Vertrauen › Bei Verwendung dieses Zertifikats: Immer vertrauen. Oder im Terminal:

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain wachtl.crt

iPhone und iPad

Diese Seite in Safari öffnen und das Zertifikat herunterladen › Einstellungen › Profil geladen › Installieren. Danach unter Einstellungen › Allgemein › Info › Zertifikatsvertrauenseinstellungen das Wachtl-Zertifikat einschalten.

Android

Zertifikat herunterladen › Einstellungen › Sicherheit › Weitere Sicherheitseinstellungen › Verschlüsselung und Anmeldedaten › Zertifikat installieren › CA-Zertifikat (Bezeichnungen je nach Hersteller leicht anders). Chrome vertraut ihm danach; einzelne Apps können eigene Regeln haben.

Linux

sudo cp wachtl.crt /usr/local/share/ca-certificates/wachtl.crt
sudo update-ca-certificates

Firefox und Chrome unter Linux nutzen teils einen eigenen Speicher: dort unter Einstellungen › Datenschutz und Sicherheit › Zertifikate importieren.

Firefox

Unter Windows und macOS übernimmt Firefox die Stammzertifikate des Systems (Einstellung security.enterprise_roots.enabled). Sonst unter Einstellungen › Datenschutz und Sicherheit › Zertifikate anzeigen › Zertifizierungsstellen › Importieren.
