3 · Softwareverteilung

Das vorbelegte Setup läuft auch unbeaufsichtigt:

WachtlSetup-Standort.exe /VERYSILENT /SUPPRESSMSGBOXES

Mit dem Setup ohne Vorbelegung:

{{ setup_name or 'WachtlSetup.exe' }} /VERYSILENT /SUPPRESSMSGBOXES /Server="{{ server_urls|join(',') }}" /Pin="{{ pin }}" /Token="{{ token }}"

Exit-Code 0 = Probe installiert und angemeldet (oder Anmeldung folgt automatisch, sobald der Server erreichbar ist).
